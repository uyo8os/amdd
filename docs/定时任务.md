这是一个完整的 **Linux 定时任务管理脚本**，你只需运行这个脚本，即可完成以下功能：

- ✅ 同步北京时间（使用 ntpdate）
- ✅ 添加 systemctl 重启任务（支持多种固定时间间隔和自定义时间）
- ✅ 自动生成脚本、设置日志、定时执行
- ✅ 查看当前所有任务及其日志
- ✅ 删除已添加的任务
- ✅ 操作后返回菜单，不会中断
- ✅ 自动重载 Cron 服务
- ✅ 全程日志隔离管理

## 一键安装：

```
bash <(curl -Ls https://raw.githubusercontent.com/uyo8os/amdd/main/cron_manager.sh)
```



## 📌 手动使用方法：

1. **保存脚本**

   ```
   nano /usr/local/bin/cron_manager.sh
   ```

2. **赋予执行权限**

   ```
   chmod +x /usr/local/bin/cron_manager.sh
   ```

3. **运行脚本**

   ```
   /usr/local/bin/cron_manager.sh
   ```

4. **或者**

   ```
   chmod +x cron_manager.sh && ./cron_manager.sh
   ```


## 📂 文件结构总览

```
├── etc/
│   └── Cron/
│       ├── V2bX              # 自动生成的任务执行脚本（例如重启 V2bX.service）
│       └── ...               # 每个任务一个独立脚本，文件名为服务名
├── var/
│   └── log/
│       └── cron_tasks/
│           ├── task_V2bX.log      # 每个任务的独立日志文件
│           └── task_*.log         # 其他任务的日志文件
├── tmp/
│   └── current_crontab.bak   # 当前 crontab 的备份临时文件
└── usr/
    └── local/
        └── bin/
            └── cron_manager.sh    # 主脚本文件（你手动保存）
```

------

## 📁 各目录作用说明

| 路径                             | 用途                                                         |
| -------------------------------- | ------------------------------------------------------------ |
| `/etc/Cron/`                     | 存放所有生成的任务脚本，例如重启服务等任务。每个任务独立一个脚本 |
| `/var/log/cron_tasks/`           | 每个任务一个日志文件，自动追加写入输出与错误信息             |
| `/tmp/current_crontab.bak`       | 当前系统 crontab 的临时备份，用于更新任务时安全修改          |
| `/usr/local/bin/cron_manager.sh` | 你运行的主控制脚本，提供菜单式交互管理任务                   |



## ✅ 示例说明（以 V2bX 为例）

### 添加任务时自动生成的文件：

#### 📄 脚本文件 `/etc/Cron/V2bX`：

```
PATH=/bin:/sbin:/usr/bin:/usr/sbin:/usr/local/bin:/usr/local/sbin
export PATH

echo "----------------------------------------------------------------------------"
echo "→ 正在执行：systemctl restart V2bX.service"
systemctl restart V2bX.service
if [ $? -eq 0 ]; then
    echo "★[$(date +"%Y-%m-%d %H:%M:%S")] ✅ 重启成功"
else
    echo "★[$(date +"%Y-%m-%d %H:%M:%S")] ❌ 重启失败"
fi
echo "----------------------------------------------------------------------------"
```

#### 📄 日志文件 `/var/log/cron_tasks/task_V2bX.log`

- 自动记录该脚本运行的输出和错误信息，方便排查问题或查看执行历史。

------

## ⏱ 定时任务在 crontab 中的样例：

```
0 * * * * /etc/Cron/V2bX >> /var/log/cron_tasks/task_V2bX.log 2>&1
```
